# Agent 化架构优化 — 执行顺序

> 日期：2026-10-30
> 依据：`docs/Agent化架构优化方案.md`（P0–P5 路线图 + 第 4 节度量地基 + 第 6 节风险）
> 配套项目级 skill：`bysj-safe-code-change`（安全层与模块规范）、`bysj-ui`（前端约定）

## 排序依据

三条硬约束决定先后顺序：

1. **度量先行**：方案第 4 节是地基，没有基线指标，后续每步都无法验收，也无法支撑论文/答辩论据。
2. **安全先于工作流**：Workflow 运行器的挂起/审批语义依赖真实审批与身份绑定，不能建立在 `_confirm` 之上。
3. **契约先于运行器**：运行器的重试/恢复依赖错误分类（retryable 等）与步骤级幂等键复用。

## 阶段 0：度量与环境地基（先于一切代码改动）

| # | 任务 | 交付物 | 验收 |
| --- | --- | --- | --- |
| 0.1 | 冻结 AGH 版本 + 复现步骤 | `agh-integration/README.md` 增补版本/构建/启动记录 | 从零环境按文档可复现启动 |
| 0.2 | 定义 Golden 评估集 | 固定数据快照 + 算法 seed + 6 场景定义（设备故障/紧急插单/混合扰动/不可行解/重复告警/审批拒绝） | 场景可重复触发 |
| 0.3 | 采集现状基线 | 用当前 Skill 驱动方案跑评估集，记录成功率/误操作/人工介入率/步骤数/耗时/token，存 `evidence/` | 同 seed 两次运行结果一致 |
| 0.4 | 隔离回归环境 | 独立数据库 + 独立凭据 + 独立端口 | CI/回归不触碰演示环境 |

## 阶段 1：安全边界（方案 P0 安全部分）

## 阶段 2：工具契约（方案 P1）

| # | 任务 | 说明 | 验收 |
| --- | --- | --- | --- |
| 2.1 | 入参运行时校验 | 复用 `fjsp-tools/index.mjs` 已有 schema，执行前拦截 | 非法参数挡在执行前 |
| 2.2 | 出参 + 错误 envelope + 契约测试 | 不再靠描述文字约束 | 契约测试通过 |
| 2.3 | 错误分类 | `retryable / needs-input / needs-human / terminal`；`E_EVENT_IN_PROCESS`、`FJSP_INVALID_STATE` 专门分支 | 每错误有分类与恢复动作 |
| 2.4 | 步骤级幂等键复用 | 改造每次请求新 UUID；超时/断连先查业务终态 | 重复投递不产生第二次写入 |
| 2.5 | BFF 共享 typed schema（可与 2.1–2.4 并行） | HTTP 生成 OpenAPI，SSE 事件独立版本化 | 前后端契约测试通过 |

## 阶段 3：Workflow 运行器（方案 P2，核心阶段）

| # | 任务 | 说明 | 验收 |
| --- | --- | --- | --- |
| 3.1 | 检查点存储 + 恢复协议 | 最小检查点：workflowId、去重键、业务对象 ID、当前节点、尝试次数、步骤幂等键、待审批 | 单实例可恢复 |
| 3.2 | 扰动处置流程骨架 | SKILL.md 流程部分翻译成确定性代码，mock 工具测分支 | 分支测试覆盖异常路径 |
| 3.3 | Agent 决策节点契约 | 输出 `{mode, weights, rationale}`，校验枚举/数值范围后才执行 | 非法建议被拒绝 |
| 3.4 | 人工挂起/恢复接入真实审批 | 依赖阶段 1 的审批绑定 | 评审/发布为一等挂起节点 |
| 3.5 | 恢复回归 | 重启/超时/重复告警/乐观锁冲突 | 均达预期终态且不重复写入 |

完成后 SKILL.md 瘦身：只留方法论，流程交代码。评估集复测对比阶段 0 基线。

## 执行方式约定

- 每阶段开工前 `writing-plans` 写计划，执行用 `executing-plans` / `subagent-driven-development`；代码改动全程挂 `bysj-safe-code-change`（大改动分批确认）；功能/bugfix 用 `test-driven-development`；交接前 `verification-before-completion`。
- 串行为主；可并行的仅：2.5 ∥ (2.1–2.4)、5.1 ∥ 阶段 4。
- 每阶段结束把测试场景、指标、证据归档 `agh-integration/evidence/`；架构类改动同步更新架构图。
- 不用"脚本全绿"替代效果评估。
