# 浅色专业工业控制台 UI 改造说明

## 目标
在不改变业务功能、接口和路由的前提下，统一 FJSP OPS 的视觉语言，解决界面泛白、层级弱、图标与组件风格不一致的问题。

## 已确认方向
- 浅色专业工业控制台，不做全站深色大屏。
- 保留品牌蓝；深灰正文、浅灰工作区、白色内容面板。
- 红色仅用于故障与危险操作，绿色仅用于运行与成功。
- 第一批范围为全局基础样式、应用外壳、调度看板和设备管理两个样板页。
- 样板验收后再推广到其他页面。

## 设计约束
- 保留 Vue 3 Composition API、Element Plus、现有 API 封装与业务逻辑。
- 不引入新的 UI 框架或图标依赖。
- 统一页面标题、正文、辅助文字、间距、圆角、按钮、表格和状态标签。
- 使用统一 SVG 图标替换侧栏字符图标。
- 保持键盘焦点、权限显隐、加载/错误/空数据状态。
- 最小桌面宽度沿用现有约定，重点验证 1280×720 与 1440×900。
- 数字孪生的三维模型与交互不属于本批改造范围。

## 验收
- 两个样板页在空数据、正常数据和刷新场景下布局稳定。
- 侧栏导航、分组折叠、返回、AI 面板入口和权限显隐不变。
- 设备编辑弹窗仅做打开/关闭验证，不提交业务修改。
- `npm test`、`npm run build`、`scripts/ui-check.sh` 通过，无横向页面溢出。
