# 08 公开内容

> 对应比赛要求 4.2 第⑧项：公开内容（≥1 条真实项目内容，含平台、有效链接、截图与发布日期）。

## 要求与现状

比赛要求提交至少 1 条已公开发布的、与本项目相关的真实内容，需提供：平台名称、有效链接、发布页面截图、发布日期。

**现状：【待办】尚未发布任何公开内容。** 以下给出 3 个可选发布方案，任选其一（或多项）执行；发布后回填下方「回填区」。

## 回填区（发布后填写）

| 字段 | 内容 |
|------|------|
| 平台 | 【待填：平台名称】 |
| 链接 | 【待填：有效链接】 |
| 截图 | 【待填：截图文件名，建议存于 submission/screenshots/】 |
| 发布日期 | 【待填：YYYY-MM-DD】 |

（如发布多条，复制上表继续填写。）

## 方案 A：GitHub 公开仓库（推荐，可同时补齐「在线代码仓库」）

1. 在 GitHub 创建公开仓库（如 `fjsp-dispatch-system`）；
2. 本地添加 remote 并推送：`git remote add origin <repo-url> && git push -u origin main`（注意确认 `.env`、凭据文件未被推送——`.env.example` 仅有占位符，真实 Key 在 `~/.config/fjsp/agnes.env`）；
3. 仓库 README 置顶项目简介与复现步骤（引用 `submission/03-可运行作品与复现说明.md`）；
4. 回填字段：平台 = GitHub；链接 = 仓库 URL；截图 = 仓库首页截图；发布日期 = 推送当日。

## 方案 B：技术博文（CSDN / 知乎 / 掘金任选）

1. 撰写一篇项目技术文章，建议主题：「AGH + Agnes 模型驱动下的动态柔性车间调度闭环实践」，内容可基于 `02-技术信息.md` 与 `05-运行证据说明.md` 改写，含架构图、调用链、KPI 结果；
2. 发布为公开文章（不设仅自己可见/不设登录墙）；
3. 回填字段：平台 = CSDN/知乎/掘金；链接 = 文章 URL；截图 = 文章页截图；发布日期 = 发布当日。

## 方案 C：B 站公开视频（可与演示视频复用）

1. 将演示视频（见 `04-演示视频脚本.md`）上传 B 站并设为公开；
2. 视频简介中注明项目名称与技术栈；
3. 回填字段：平台 = 哔哩哔哩；链接 = 视频 BV 号链接；截图 = 播放页截图；发布日期 = 过审发布当日。

## 注意事项

- 发布内容须为**真实项目内容**，与提交作品一致，不得发布与项目无关的凑数内容；
- 链接须保证评审期间持续有效、免登录可访问；发布后请用无痕窗口验证；
- 若发布多条，至少 1 条须完整回填四项字段。
