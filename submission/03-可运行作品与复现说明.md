# 03 可运行作品与复现说明

## 提交形式说明

- **在线体验链接**：本项目不提供在线体验链接；系统为本地单车间部署形态，以公开代码仓库、ZIP 安装包与可复现运行说明交付。
- **代码仓库**：<https://github.com/xyzlily215-cmyk/fjsp-dispatch-system>（GitHub 公开仓库，2026-10-09 上线，与 ZIP 内源码一致）。
- **当前提交形式**：**ZIP 安装包（完整源码快照）+ 本可复现运行说明**。ZIP 由 `submission/build-zip.sh` 生成，含 `git archive HEAD` 源码、`submission/` 材料与 `agh-integration/agh-trace-20261003.zip` 证据包。

## 环境要求

| 依赖 | 版本要求 | 用途 |
|------|----------|------|
| 操作系统 | macOS / Linux | 启动脚本为 bash |
| Python | 3.11+ | 算法服务 |
| Node.js | ≥ 24.10 | AGH 运行底座 |
| Java | 17+ | 业务服务 |
| Maven | 3.6.3+（开发环境为 3.9.0） | 业务服务构建 |
| Docker + Docker Compose | 任意近期版本 | PostgreSQL 16 容器 |

## 复现步骤

### 1. 解压 ZIP

```bash
unzip 组别-参赛编号-队伍名称-队长姓名.zip -d fjsp
cd fjsp
```

### 2. 安装依赖（一次性）

```bash
pip install -r algorithm-service/requirements.txt
cd web-vue && npm install && npm run build && cd ..
cp .env.example .env
# 编辑 .env，设置 FJSP_DB_PASSWORD（数据库密码）
```

### 3. 一键启动

```bash
bash scripts/start-demo.sh
```

该脚本依次拉起：PostgreSQL（Docker Compose）→ 算法服务（8101）→ 业务服务（8081）→ 前端（8082）→ AGH 工作台（4177）。

如暂不体验 AGH 智能体部分，可跳过：

```bash
FJSP_START_AGH=0 bash scripts/start-demo.sh
```

### 4. 访问入口

| 入口 | 地址 |
|------|------|
| 前端界面 | `http://127.0.0.1:8082/index.html?api=http://localhost:8081/api/v1` |
| 业务 API | `http://localhost:8081/api/v1` |
| 算法服务 | `http://localhost:8101` |
| AGH 工作台 | `http://localhost:4177` |

### 5. 验证运行

```bash
# 算法服务健康检查
curl http://localhost:8101/health

# 前端字段契约 E2E（401→登录→reset→建基线→轮询→版本分页，逐接口断言）
node scripts/e2e-api-check.mjs

# 业务全流程冒烟（基线→审核→发布→故障/插单→重调度→并发发布→执行反馈→审计校验）
bash business-service/scripts/smoke-test.sh

# 基础数据写接口正/负例
bash scripts/crud-check.sh

# 算法服务单元测试（56 个）
cd algorithm-service && python3 -m pytest

# 业务服务测试（53 个测试类，集成测试使用 Testcontainers，需 Docker）
cd business-service && mvn test
```

算法服务自带演示算例 `demo_instance.json`（20 订单 / 8 设备），无需额外准备数据即可复现排程结果。

## AGH 智能体部分（可选）

AGH 部分需要评审方自备 Agnes API Key：

1. 按 `agh-integration/README.md` 执行 AGH CLI config 向导，Provider 选 **Agnes AI**，网关 `https://api.agnes-ai.cn/v1`，模型 `agnes-3.0-flash`；
2. 凭据写入 `~/.config/fjsp/agnes.env`（不入仓库；仓库内 `.env.example` 仅有 `# AGNES_API_KEY=` 占位）；
3. 启动 AGH 工作台（4177）后，即可用中文指令驱动，例如「帮我完成基线排程并发布」「M-03 发生故障，请处置」；
4. 无 Key 时可用 `FJSP_START_AGH=0` 跳过，系统其余功能不受影响。
