## ZIP 打包说明

使用 `submission/build-zip.sh` 一键打包：

```bash
bash submission/build-zip.sh 本科生组 U019 暴躁的兔子 熊英孜
# 生成：本科生组-U019-暴躁的兔子-熊英孜.zip
```

脚本行为：

1. 检查 `submission/` 与 `agh-integration/` 之外是否有未提交改动；有则拒绝打包，避免遗漏源码。
2. 以 `git archive HEAD` 导出源码，叠加当前 `submission/` 与 `agh-integration/` 工作区，并加入 AGH 上游源码快照及运行证据包。
3. 用 Python 标准库生成支持中文文件名的 UTF-8 ZIP，按 `组别-参赛编号-队伍名称-队长姓名.zip` 命名，并检查 200MB 上限。本次因本地代码有未提交改动，在临时副本中提交同一套已验证代码后调用了本脚本；原工作区未提交状态保持不变。视频按赛事要求只提供分享链接，临时打包副本不收录本地原始 `.mov` 素材。
