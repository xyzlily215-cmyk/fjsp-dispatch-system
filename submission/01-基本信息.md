# 01 基本信息

## 项目名称

动态柔性车间生产调度与仿真决策系统

## 参考方向

- 工业软件 / 智能制造

## 项目摘要

本项目是一套面向单车间的动态柔性车间生产调度与仿真决策系统，源自本科毕业设计改造。系统覆盖「基础数据维护 → 基线排程 → 事件录入（设备故障 / 紧急插单）→ 局部 / 完全重调度 → 方案对比 → 审核发布 → 执行反馈」的完整业务闭环。调度内核为自研混合遗传算法（算法版本 `event-adaptive-hga-1.0.0`），演示规模 20 订单 / 8 设备（上限 50/12），输出 makespan、加权拖期、负载不均衡度等可量化 KPI。系统以 AGH（Agnes Harness）为智能体运行底座，全部模型调用仅使用 Agnes 模型（agnes-3.0-flash），通过自研的 16 个 `fjsp_*` AGH 工具插件把排程、重调度、对比、评审、发布等业务能力暴露给智能体，并以四级审批策略实现「提交评审 → 人工确认 → 审批 → 发布」的人机协同管控。系统还具备 MHS 设备接入能力：车间设备经 MHS / AgnesHub 接入，异常自动上报并唤醒 Agent 处置；已接入与业务清单对齐的 8 台虚拟机床（cnc-m01~m08，含车间地图与状态面板画面，故障演示机 cnc-m03 对应业务机台 M-03）并通过 MHS 一致性检查（37 pass / 0 fail）。扰动处置具备 RSI 经验闭环：处置结果沉淀为经验，同类事件再次发生时自动推荐历史最优策略。系统提供看板、甘特图、方案对比、Agent 处置时间线等 19 个前端视图，具备幂等、乐观锁、审计等企业级特性，并通过 AGH 端到端执行轨迹、57 项算法测试、41 个业务单元测试类与 11 个 Testcontainers 集成测试类、以及全流程冒烟脚本形成完整证据链。

## 问题来源与目标

### 问题来源

柔性作业车间在实际生产中普遍依赖人工经验或静态排程。一旦发生紧急插单、设备故障等扰动，原定计划需要反复人工调整，容易出现：

- 资源冲突（同一设备时间重叠）；
- 工艺顺序错误（工序先后约束被破坏）；
- 交期失控（拖期无法量化评估与对比）。

同时，调整过程缺乏可解释的方案对比与审批留痕，决策责任难以追溯。

### 项目目标

构建并验证一套「动态调度决策 + 可解释展示」的闭环系统：

1. 基线排程自动化，输出可量化 KPI；
2. 扰动事件（故障 / 插单）触发局部或完全重调度，支持冻结窗口与硬锁定，保证在制工序不被破坏；
3. 多方案 KPI 对比与甘特图可视化，支撑可解释决策；
4. 引入 AGH + Agnes 模型作为智能体入口，实现自然语言驱动的调度操作，并以分级审批保证高风险操作人工可控；
5. 以自动化测试与运行证据链保证结果可复现、可审计。
