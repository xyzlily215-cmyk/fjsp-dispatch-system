# 06 测试样例

> 对应比赛要求 4.2 第⑥项：测试样例（正常、边界、失败三类）。

测试资产分布：算法服务 pytest（`algorithm-service/tests/`，13 个文件 56 个测试）、业务服务 JUnit（53 个测试类，单元 + Testcontainers 集成）、端到端/冒烟脚本（`scripts/e2e-api-check.mjs`、`business-service/scripts/smoke-test.sh`、`scripts/crud-check.sh`）。以下按正常 / 边界 / 失败三类各取代表性用例。

## 一、正常类

| 用例 | 类型 | 所在文件 | 输入 | 预期 | 实际结果 |
|------|------|----------|------|------|----------|
| 求解接口与校验回环 | 算法·API | `algorithm-service/tests/test_api.py::test_solve_endpoint_and_validate_roundtrip` | 合法 FJSP 实例（演示算例结构）POST /solve | 返回可行解，且解通过 validate 校验回环 | 通过 |
| KPI 计算正确性 | 算法·单元 | `algorithm-service/tests/test_kpi.py` | 已知排程结果 | makespan / 加权拖期 / 负载不均衡度等指标计算正确 | 通过 |
| 质量基线 | 算法·单元 | `algorithm-service/tests/test_quality_baseline.py` | 基准算例求解 | 解质量不低于既定基线阈值 | 通过 |
| 同种子可复现 | 算法·单元 | `algorithm-service/tests/test_reproducibility.py` | 相同实例 + 相同随机种子求解两次 | 两次结果一致 | 通过 |
| 前端字段契约 E2E | 端到端 | `scripts/e2e-api-check.mjs` | 401→登录→reset→建基线→轮询→版本分页 | 逐接口断言响应包络符合前端契约 | 通过 |
| 全流程冒烟 | 集成 | `business-service/scripts/smoke-test.sh` | 基线→审核→发布→故障/插单→重调度→执行反馈 | 全链路状态流转正确，审计落库且 `X-Source`/`X-AGH-Session-Id` 透传（直连 PG 校验） | 通过 |

## 二、边界类

| 用例 | 类型 | 所在文件 | 输入 | 预期 | 实际结果 |
|------|------|----------|------|------|----------|
| 冻结窗口 | 算法·单元 | `algorithm-service/tests/test_freeze_window.py` | 带冻结窗口的重调度请求 | 冻结窗口内工序不被改动，窗口外正常重排 | 通过 |
| 重调度硬锁定 / 加工中锚定 | 算法·单元 | `algorithm-service/tests/test_reschedule.py` | 含加工中工序的重调度请求 | 在制工序被硬锁定锚定，不被重排破坏 | 通过 |
| 请求校验边界 | 算法·单元 | `algorithm-service/tests/test_validation.py` | 边界取值 / 缺省字段的请求 | 按契约接受或给出结构化校验错误 | 通过 |
| 解码器边界 | 算法·单元 | `algorithm-service/tests/test_decoder.py` | 边界染色体 / 编码序列 | 解码输出满足工艺与资源约束 | 通过 |
| 并发发布乐观锁 | 业务·集成 | `business-service/src/test/`（并发发布用例，Testcontainers） | 两个请求并发发布同一方案 | 其一成功，另一返回 `E_VERSION_STALE` | 通过 |
| 幂等重放 | 业务·集成 | `business-service/src/test/`（幂等用例） | 相同 `Idempotency-Key` 重复提交写请求 | 不产生重复记录，返回首个结果 | 通过 |

## 三、失败类

| 用例 | 类型 | 所在文件 | 输入 | 预期 | 实际结果 |
|------|------|----------|------|------|----------|
| 未知设备不可行 | 算法·负例 | `algorithm-service/tests/test_solve_infeasible_unknown_machine.py` | 工序引用不存在设备的实例 | 判定不可行并给出明确原因 | 通过 |
| 未预期异常结构化 500 | 算法·负例 | `algorithm-service/tests/test_unexpected_error_returns_structured_500.py` | 触发内部异常的请求 | 返回结构化 500 错误体，不泄露堆栈 | 通过 |
| 请求体超限拒绝 | 算法·负例 | `algorithm-service/tests/test_request_size_limits_rejected.py` | 超过大小上限的请求体 | 请求被拒绝并返回对应错误 | 通过 |
| 设备时间重叠检测 | 算法·校验器负例 | `algorithm-service/tests/test_machine_overlap_detected.py` | 同设备时间重叠的非法解 | 校验器检出重叠并报错 | 通过 |
| 重复设备编码 | 业务·脚本负例 | `scripts/crud-check.sh` | 重复 `machineCode` 创建设备 | 返回 `E_DUPLICATE` | 通过 |
| 空编码校验 | 业务·脚本负例 | `scripts/crud-check.sh` | 空编码创建请求 | 返回 `E_VALIDATION` | 通过 |
| 权限矩阵拒绝 | 业务·集成 | `business-service/src/test/`（权限矩阵用例） | 无权限角色调用受保护接口 | 访问被拒绝 | 通过 |
| 导入回滚 | 业务·集成 | `business-service/src/test/`（导入用例） | 含错误数据的批量导入 | 整体回滚，不留半截数据 | 通过 |

## 复现方式

```bash
cd algorithm-service && python3 -m pytest        # 56 个算法测试
cd business-service && mvn test                  # 53 个测试类（集成需 Docker）
node scripts/e2e-api-check.mjs                   # 前端契约 E2E（需服务已启动）
bash business-service/scripts/smoke-test.sh      # 全流程冒烟
bash scripts/crud-check.sh                       # 基础数据正/负例
```
